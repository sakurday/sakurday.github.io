# HFUT Vanilla 26.1.2原版服介绍

## 服务器简介

HFUT原版服开设于2025年11月末，是HFUT MC社区的重要组成部分。本服务器保留了原版原汁原味的体验，同时通过插件增强了玩家的游戏体验。
本服务器作为原版服，没有花里胡哨的氪金/领地/经济/称号系统，每个人在服务器里都可以自由探索。

你是在远处默默建造自己家园的休闲玩家？是立志造出百万产量机器的生电玩家？是想建造宏大宫殿的建筑玩家？还是单纯想在服务器里和群友吹水聊天的社牛玩家？那么HFUT Vanilla服务器一定会很合你的胃口！

## 进入方式

要进入HFUT Vanilla服务器，您需要一个LittleSkin账号，并在启动器使用LittleSkin登录游戏。

您需要使用**Minecraft Java版 26.1.2**版本进入游戏。无须安装任何模组即可进入。

您可以使用HFUT服务器IP直接进入原版服。HFUT原版服的IP如下：

```
sakurafrp合肥：hf.456258hf.com
sakurafrp湖北：hb.456258hf.com
sakurafrp石家庄：sjz.456258hf.com
ipv4直连：apv4.456258hf.com
ipv6直连：apv6.456258hf.com
```

如果进入后发现您不处于原版服，您可以使用以下命令进入原版服:

```
/server Survival
```

### 服务端的模组与插件

本列表仅列出会影响玩家体验的插件和模组。对于休闲玩家，您可以忽略这部分内容。

- Velocity：用于通过同一IP游玩多个服务器。您可以使用```/server <Name>```进入你想要的其他HFUT服务器。

- TAB：可以在玩家列表显示玩家处于的HFUT服务器。

- VeloChatX：让玩家可以跨服聊天，并显示玩家进入了什么服务器。

- PrimeBackup：可以让玩家进行服务器存档的备份与恢复。（```!!pb (make|list|back```）

- Jade：如果您安装了Jade模组，可以显示容器、方块、实体的高级信息。

- JEI：如果您安装了JEI模组，可以正常查询合成表，以及使用快捷填充功能。

- Servux：如果您安装了MiniHUD，可以同步一些服务器信息。

- Syncmatica：如果您安装了Litematica（投影模组），可以与其他玩家共享投影原理图。

- Carpet及若干附属：对游戏某些机制进行更改，优化游戏体验。被修改的规则见文章末尾。

### 玩家规则

**在不影响其他玩家游玩体验的前提下**，您可以适当使用辅助模组，如Tweakeroo，Wurst，矿透，投影等等。

请文明友善与其他玩家交流。
