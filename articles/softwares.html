好用的软件搜集

这个页面搜集了很多好用的软件，都是我一直在用的，其中大部分都是免费或开源的。需要付费的我会标出来。

这个页面是我为好用软件的下载链接存了备份，但是也可以帮助别人。

文本编辑器

Sublime Text

免费。非常轻的编辑器，秒开

Obsidian

免费开源。markdown编辑器，记笔记好用

Microsoft VS Code

免费开源。算不上轻也算不上重，写代码还行

NeoVim

免费开源。终端里的编辑器，比较难用，需要适应

浏览器

Firefox

免费开源

Chrome

免费

Edge

一坨粑粑，我不放链接了

看图

Honeyview

免费。非常轻快

视频播放

VLC

免费开源。非常轻快。界面比较原始但是非常好用，比起PotPlayer不知道好用多少倍

截屏录屏

OBS Studio

免费开源。录屏

Snipaste

免费。截图

图片编辑

Aseprite

付费开源。你可以自己下源码编译这样就免费了。图片编辑，小号PS，最适合像素图片。

Microsoft PowerPoint

付费。虽然是做ppt用的但是做海报这种好用捏

Krita

免费开源。许多画师都在用的画画软件，也可以当PS。

Adobe Photoshop

请输入文本

格式转换

格式工厂

免费。虽然爆过雷但是比较轮椅，本身也没啥广告。转换很多格式都挺好用

File Converter

免费开源。右键菜单一键转换，最方便的一集。大多数格式都能转

Caesium image compressor

免费开源。压缩图片的神

PDF24

免费。PDF万能工具箱。记得下本地版，在线版加载太慢了。

远程控制

网易UU远程

免费。轮椅

Sunshine

免费开源。有点折腾，对网络环境有特殊要求。

Moonlight

Sunshine配套的控制端

剪辑

剪映

免费但有内购。轮椅

Kdenlive

免费开源。教程较少

Adobe Premiere

请输入文本

压缩软件

Nanazip

免费开源。7-zip改版，界面更好看

7-zip

免费开源。丑不拉几的像是原始人写出来的

跨设备互联

Localsend

免费开源。不同设备传文件最好用

Scrcpy

免费开源。电脑操控手机最好用的

杀毒软件

360

免费。请下载极速版并在设置里关闭广告。杀毒这一块没人比得过他，而且极速版相对来说很干净。

卡巴斯基

免费。能力稍逊于360，但好歹是全球顶级的。免费版功能较少，买标准版很便宜。

火绒

免费。为了杀毒的话还不如不装，如果是为了顶掉Windows defender的话还有点用。

梯子

FlClash

免费开源。轻快简洁的梯子工具，也是大部分机场推荐的软件

系统工具

喜欢折腾系统的有福了

Hibit Uninstaller

免费。卸载软件的工具

Everything

免费。搜索文件的工具

VMWare

免费。虚拟机。下载有点麻烦

LM Studio

免费。本地部署AI非常方便，自带下载

Explorer Patcher

免费开源。将开始菜单、任务栏、右键等恢复成win10的操作方式

Minecraft启动器

PCL

免费开源。网上盗版一大堆，只有我才会给你放官方链接，快说谢谢Sakurday

Prism Launcher

免费开源。本身是一款好用的启动器，在我心目中超越了PCL。但是针对国内网络环境没有优化，不推荐给大多数人。
