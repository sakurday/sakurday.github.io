## 关于这个网站的实现方式

正如这个仓库展现的那样，此网站托管于GitHub，使用GitHub pages免费构建了这个静态网站。

此网站使用 Jekyll 构建，主题来源于 Google Material 3 Design 库，网站骨架是 Codex 帮我搭建的，但是网站任何你能直接看到的东西都不是 AI 生成的（文字，图标，主题，因为主题是直接引用的 M3web 库所以严格来讲不是 AI 生成的）。
